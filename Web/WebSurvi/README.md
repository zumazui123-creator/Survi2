# Survi 2

## Game built with Godot

**Survi 2** is a game developed entirely with the **Godot Engine**.  
All game logic, AI behavior, and interactions are handled directly inside Godot.

---

## How to Install

### Godot Game

1. Install **Godot Engine** (use the version recommended for this project).
2. Open the project in Godot.
3. Run the game from the editor  
   **or**
4. Export the game using Godot’s standard export tools for your target platform.

---

## Usage

1. Launch the game.
2. Play directly
